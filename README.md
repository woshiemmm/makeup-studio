# 妆 · 妆造教学

一个中文化妆教学网站：从**妆前准备**到**妆后护肤**的完整图文 + 公开视频教学，
支持**妆容识别**与**肤质分析**，并可根据肤质灵活定制每一步。

同一份代码有两种跑法：

| | 本地版 | 公网版 |
|---|---|---|
| 打开方式 | 双击 `start.bat` → `http://127.0.0.1:8787` | Cloudflare Pages 给的公开网址 |
| 访问范围 | 只有你自己 | 所有人，可被搜索引擎收录 |
| AI 接口 | 本地代理转发，Key 由你在网页里填 | Cloudflare Functions 代理，Key 存在服务端 |
| 适用场景 | 自己用真 AI，效果最好 | 分享给他人、被搜到 |

> **部署到公网、以及如何被搜索引擎搜到，请看 [DEPLOY.md](DEPLOY.md)。**

## 一、两种使用方式

### 方式 A：直接打开（离线、免费、无需配置）

双击 `index.html` 即可。

- 教学内容、配图、视频链接全部可用
- 「妆容识别」和「肤质分析」使用**内置演示模式**：
  在本地读取图片像素，分析主色调 / 明暗 / 饱和度后匹配妆容与肤质建议
- 完全离线，不联网、不消耗任何额度

### 方式 B：启动本地服务（接入 DeepSeek AI，推荐）

双击 **`start.bat`**。

脚本会自动找到 Node 并启动本地服务，然后打开浏览器访问
<http://127.0.0.1:8787>。这个服务做两件事：

1. 把本目录作为网站托管（比 `file://` 更稳定）
2. 把 `/v1/chat/completions` 代理到 `https://api.deepseek.com`
   并补上 CORS 响应头 —— **绕开浏览器跨域限制**

> 为什么需要代理？浏览器直接从网页里调用各家大模型 API 通常会被跨域（CORS）拦截，
> 这是浏览器的安全策略。本地代理是官方推荐的绕过方式，同时也让 API Key 不进入网页代码。

## 二、配置 DeepSeek API

### 1. 获取 API Key

到 DeepSeek 开放平台 <https://platform.deepseek.com/> 注册并创建 API Key（形如 `sk-...`）。

### 2. 在网页里填写

打开网页 → 左侧 **「设置」**：

| 项目 | 填写内容 |
|---|---|
| AI 识别模式 | 自动（推荐） |
| 供应商预设 | **DeepSeek 本地代理（推荐）** |
| API Key | 你的 `sk-...` |
| 接口地址 Base URL | `http://127.0.0.1:8787/v1` |
| 模型名称 Model | `deepseek-flash` |

点击 **「🔌 测试连接」** 验证，看到 ✅ 即表示接通；再点 **「💾 保存配置」**。

### 3. 关于模型

DeepSeek 支持图片输入的模型是 **`deepseek-flash`**（多模态），
这正是识图和脸部分析需要的。旧名 `deepseek-v4-flash-vision-exp` 也仍可调用。

参考文档：<https://api-docs.deepseek.com/zh-cn/guides/vision/>

### 4. （可选）不在网页里存 Key

编辑 `start.bat`，取消这一行的注释并填入你的 Key：

```bat
set "DEEPSEEK_API_KEY=sk-your-key-here"
```

这样 Key 只存在于本地服务进程，网页里可以不填。

---

## 三、不想用代理？

在「设置」里把供应商换成 **「DeepSeek 官方 API（直连）」**，
Base URL 用 `https://api.deepseek.com`，再填 Key。

多数情况下浏览器会因跨域而失败；此时页面会给出明确提示，换回本地代理即可。

## 四、本地账号与数据存储

网站内置了一套**完全本地**的账号系统（不需要服务器）：

- **创建 / 切换 / 重命名 / 删除账号** — 左侧边栏顶部点击头像即可管理，或到「设置 → 账号与数据」
- **每个账号数据独立** — 「我的妆容」和「肤质档案」互不干扰
- **我的妆容** — 在「妆容识别」里上传图片 → 识别 → 点「💾 保存到我的妆容」，
  可自定义名称、加备注，并支持搜索、重命名、删除、一键「按此教学」
- **肤质档案** — 生成分析报告后自动存入当前账号，下次打开仍能看到

存储用量可在「设置 → 账号与数据」查看（上限约 5 MB，图片会自动压缩到 460px）。
每个账号最多保存 40 个妆容。

> ⚠️ **重要**：账号与数据都保存在**当前浏览器**里，不会上传到任何服务器。
> 换设备、换浏览器、或清除浏览器数据后会丢失。
> 如需跨设备同步，需要接入云端数据库（Cloudflare D1），详见 [DEPLOY.md](DEPLOY.md)。

## 五、常见问题

**端口被占用**
换端口启动：
```bat
set PORT=8899
node server.js
```
同时把设置里的 Base URL 改成 `http://127.0.0.1:8899/v1`。

**提示「无法连接接口」**
- 若用本地代理：确认 `start.bat` 的窗口还开着，先访问 <http://127.0.0.1:8787/health> 看是否返回 `ok`
- 若用直连：大概率是跨域限制，改用本地代理

**提示 401 / 402 / 429**
分别为：Key 无效、余额不足、请求过于频繁。

**识别结果不准**
演示模式只做颜色与明暗分析，属于近似判断；接入 `deepseek-flash` 后是真正的视觉理解，准确度会明显提升。
